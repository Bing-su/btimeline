# 타임라인 KDL v2 스키마

현재 문법·시계·참조·오류·투영 계약은 [Timeline v2](../../../../docs/timeline-v2.md)에 있다. 이 파일의 이전 v1 초안은 현재 계약이 아니다. `timeline 2`만 로드하며 `process 1`과 recording `version: 1`은 별개다.

작성 절차는 [저작 합의](agent-timeline-authoring.md), 생성은 [생성 계약](generation.md), 관측 재생과 한계는 [오프라인 재생](offline-replay.md), 평가 프로필은 [작성 평가](authored-evaluation.md)를 함께 따른다. 실제 ACT 미검증을 명시하고 기존 관측·사용자 데이터를 보존한다.
