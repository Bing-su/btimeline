## 가짜 분기 제거 및 자동 반복 출력

원인은 250ms 이내의 패킷을 시전자 역할과 시전 ID 순으로 다시 정렬한 것이었다. Chort의 마지막 `BEF2 → BEF1`은 두 로그 모두 같은 순서인데, 간격이 222ms이면 뒤집히고 265ms이면 유지됐다. 동일한 본문을 다른 경로로 해석하면서 11423·14644·17866초의 가상 블록을 만들었다.

원본의 시전자 이름을 정렬 문맥에 보존했다. 같은 이름으로 나오는 본체와 보조 개체의 시전은 실측 시각 순서를 유지하고, 서로 다른 시전자의 동시 도착은 이름으로 정렬한다. 실제 게임 분기에 대한 처리는 유지하며, 이번 가짜 분기를 만들던 순서 차이만 없앤다.

회귀 테스트는 한 시전자의 연속 공격과 동일 이름의 보조 개체가 본체보다 먼저 시전하는 경우를 각각 222ms·265ms 간격으로 비교한다. 두 경우 모두 분기 없이 원본 ID 순서를 보존한다. 기존 서로 다른 시전자의 도착 순서 반전 검사도 통과했다.

`out/clyteum.*`는 이 최종 결과로 갱신했다. 보완 전 결과와 최신 검증 파일은 `out/chort-order/`에 있다. 기존 Alexandria 별도 검증 실패 1건은 이번에 다시 실행하지 않았다. 실제 ACT·게임 수신은 검증하지 않았다.
