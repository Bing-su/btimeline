# 파동 분절과 부분 순서 대응 검증

2026-11-02 기준, 전투별 ID 규칙이나 시간 허용폭 확대 없이 두 가지 과도한 제약을 완화했다. 원본 시전·발생 그래프는 바꾸지 않으며 출력 복원과 무한 반복 학습은 별도로 판정한다.

## 변경과 거부 조건

| 변경                         | 허용                                                                                                                    | 계속 거부                                                                       |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| loop의 위치별 정상 파동 근거 | 한 로그 전체가 분절되지 않아야 한다는 조건 대신 각 위치에 정상 파동 근거 요구. 다른 로그·회차가 근거를 나누어 제공 가능 | 같은 개체의 재시전 합치기, 정상 파동 근거가 전혀 없는 위치, 본문·회차 경계 누락 |
| 유한 구간의 공통 활동 투영   | 다른 입력 구간에 없는 동반 신호가 공통 시전을 가리지 않도록 정렬 키만 투영. 제외한 동반 신호는 원본과 진단에 유지       | 부재만으로 선택지 생성, 종료 검열 구간·loop에 같은 완화 적용                    |
| 일관된 부분 순서 대응        | 신호별 횟수가 같고 내부 중복이 구분되며, 모든 로그의 묶음 사이 순서를 합친 그래프가 비순환일 때 발생 순번 대응          | 명확한 순서 모순·횟수 차이·미구분 중복·처리량 초과                              |

`petgraph`의 기존 방향 그래프와 순환 검사를 사용한다. 시간 추정은 대응이 확정된 뒤 기존 방식으로 수행한다. 추가한 유한 표시에는 sync를 만들지 않는다. 불확실성 묶음의 모든 경우를 해결하는 알고리즘은 아니며, 선택 이력·일반 반복의 통합 학습도 남아 있다.

## 실제 코퍼스 회귀

현재 대표 9개 콘텐츠·79개 입력으로 각각 재생성했다. 모든 입력·SHA-256은 `out/manifest.json`에 있고, 결과는 로컬 `out/validation/position-witness/`, `shared-activity/`, `partial-order/`에 남겼다. 9개 원본 `progression` 그래프는 기존 생성본과 동일하고 모든 KDL의 구조 검사를 통과했다.

| 콘텐츠                                                      | 기존 → 새 정의 | 결과                                                                 |
| ----------------------------------------------------------- | -------------: | -------------------------------------------------------------------- |
| Alexandria                                                  |        49 → 53 | Amalgam의 Supercell Matrix 두 시전과 Eliminator의 8FA9·Electray 복원 |
| Enuo 일반                                                   |        94 → 95 | 초반 Gaze of the Void C321 복원                                      |
| R9S·R10S·R11S·Clyteum·Mistwake·Meso Terminal·Doomtrain 일반 |           동일 | 7개 KDL 해시 유지. 기존 세 보스 loop도 유지                          |

Alexandria의 신규 네 시전은 고정 cactbot 커밋 `e79ea7f16093be5b80cda0e2d5bc8eb899d6fb4b`의 `alexandria.txt`에도 있다. 다만 8FA9는 참조에서 `--sync--`로 쓰는 신호다. 네 정의를 모두 별도 게임 기믹이라고 세지 않는다. 이 비교는 검증용이며 cactbot의 제외 ID·주기를 생산 코드에 사용하지 않았다.

위치별 loop 근거 변경만 적용했을 때는 9개 KDL이 모두 같았다. Doomtrain·Enuo의 무한 반복은 후속 부분 순서 변경까지 적용해도 여전히 0개다. 반복 부재나 참조 오류라는 판정이 아니다.

## 독립 재생과 직접 원본 대응

| 검사                        | 결과                                                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Alexandria 전체 5개         | 추가 정의 4개 × 5개 기록의 원본 노드 20개·cast 멤버 45개에 표시 예측 존재. 최근접 같은 이벤트 표시와 최대 차이 78ms                               |
| Alexandria 보고서 전체 보류 | `JzmkA9dqvhpB84Lg`의 두 fight를 빼고 3개 보고서로 학습. 보류 두 기록의 신규 정의 8개에도 예측 존재, 최대 차이 78ms                                |
| Enuo 기존 6개               | 신규 C321 예측 확인. 전멸 기록 한 개는 생성 이벤트의 직접 학습 대응이 없어 같은 신호의 원본 첫 발생으로 별도 대응. 전체 Enuo 검사 최대 차이 627ms |
| Enuo 새 보고서 2개 보류     | [수집 v2 검증 입력](collection-v2-inputs.csv)의 `gHdwYZvpfMDNk7Tb/2`, `d2jqrLPk6XAaNJRT/29`를 학습에 넣지 않고 재생. C321 예측 최대 차이 466ms    |
| 기존 loop 재생              | Malphas 28범위·Griffin 12범위·Chirurgeon 15범위에서 예측 누락·5초 초과·진단 0. 최대 차이 각각 661 / 994 / 3,019ms                                 |

새 정의 검사는 합계 원본 노드 28개·cast 멤버 53개이며 보류 기록의 평가 대상은 10개다. ambiguous·unresolved·violation·skipped 진단은 없었다. 학습 입력 변경으로 이벤트 ID가 달라진 경우에는 공유 trace의 원본 노드 대응으로 같은 발생을 식별했다. 보류 입력의 시각을 학습 일정에 주입하지 않았다.

검증은 cast를 Ability로 투영하고 raid 시작에 합성 InCombat을 넣은 KDL 재생이다. 최근접 같은 이벤트 표시 대조는 일대일 전체 경로 검증이나 ACT 신호 동등성의 증명이 아니다. Alexandria 3개 학습 생성본에는 58개 정의가 있지만 이 검사에서 독립 평가한 것은 전체 5개 생성본에 새로 추가된 네 정의다. Enuo 8개 관측용 생성본의 추가 정의 전체를 검증했다고 주장하지 않는다.

원본 대응·예측 결과는 `partial-order/added-events-replay.json`, 재현 코드는 같은 디렉터리의 `replay-added.ts`, loop 재생 결과는 `*-replay.json`에 있다. 대표 산출물에는 Alexandria 5개 입력의 53정의와 Enuo 기존 6개 입력의 95정의를 사용하고 보류용 두 보고서는 학습에 합치지 않는다.

## 회귀 테스트

| 종류      | 검사                                                                                                             |
| --------- | ---------------------------------------------------------------------------------------------------------------- |
| 분절 loop | 서로 다른 위치를 분절한 두 로그의 상호 근거 활용, 원본 멤버 18개 보존, 같은 개체 재시전·정상 근거 없는 위치 거부 |
| 공통 활동 | 한쪽에만 있는 동반 신호 때문에 공통 발생이 빠지지 않음. 동반 신호의 원본 그래프 노드는 유지                      |
| 부분 순서 | 101 / 250 / 1,000ms로 나뉜 파동 복원. 순서 순환과 한 발생 누락은 이 보완으로 복원하지 않음                       |
| 기존 규칙 | 기존 fragment·loop·property·snapshot·lifecycle 검사 유지                                                         |

다음 작업은 같은 근거를 반복·helper 소속 판정에 연결하는 것이다. 시간 근접도만으로 미분류 NPC를 승격하거나, 부분 대응을 허용했다는 이유로 회차·탈출을 확정하지 않는다.
