# 참조 타임라인 없는 전투 작성

목표는 외부 시간표가 없어도 원본 로그에서 주요 진행을 해석하고 독립 자료로 예고를 확인하는 것이다. 절차와 실행 경계는 [에이전트 작성 합의](AGENT_TIMELINE_AUTHORING.md)를 따른다.

Clyteum 첫 적용에서는 후보를 고정한 뒤 새 보고서의 적격 5개가 통과했다. 5초 전 조회 263건이 대응했고 Malphas의 실제 다음 회차도 관측됐다. 상세 범위·입력 제외·미검증 해석은 작성 기록을 따른다.

| 후보                       | 자료·현재 범위                                                                                                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Clyteum                    | [작성 KDL](../timelines/clyteum.kdl)·[해석 기록](../timelines/clyteum.authoring.md). 원본에서 세 보스의 도입·ID 대안·반복을 작성                                                  |
| 산도리아: 두 번째 반향세계 | [작성 KDL](../timelines/sandoria.kdl)·[해석 기록](../timelines/sandoria.authoring.md). 네 전투·Shijin 네 선택·동시 두 보스·이른 진행 복구를 작성. 생존 보스의 단독 후반은 범위 밖 |

최초 네 전투는 같은 보고서이므로 독립 표본 네 개로 세지 않는다. 초기 개발 12개에서 적격 10개가 통과했고, 첫 고정 후보의 새 보류 16개에서는 9개가 통과하고 7개가 실패했다. 실패를 보존하고 그 자료를 개발로 전환해 Shijin 추가 경로·이른 Kam'lanaut·공동 일정의 종료 범위를 보완했다. 확장 개발 28개 중 중복 2개를 제외한 26개가 통과했다. 수정 후보 `8568a2e`와 별도 보고서의 새 보류 16개를 내용 확인 전에 고정했고, 후보 수정 없이 16개 모두 통과했다. 사전 조회 441건 중 437건은 5초 전·4건은 선택 신호 특성상 2초 전이며 최대 오차는 1,111ms다. Genbu·Eastwind는 새 보류에 없어 개발·합성 범위이고 실제 ACT·UI·생존 보스 단독 후반은 미검증이다.

```sh

```

원본의 모든 활동을 표시로 만들지 않는다. 이름·시전자·반복 문맥으로 대표 기믹과 동반 발동을 구분하고, 위치·선택 관계를 확정할 수 없으면 그 해석은 보류한다. 시간표가 없는 것을 추정의 확실성으로 대체하지 않는다.
