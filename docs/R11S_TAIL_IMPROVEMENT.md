# R11S 후반 복원과 긴 전투 검증

목표는 Ecliptic Stampede 이후부터 관측된 전투 종료까지 자동 생성 범위를 확장하는 것이다. 입력 로그와 mode만 받는 CLI를 유지한다. 긴 미처치 로그를 완료 로그로 바꾸거나, FFLogs fight 종료를 ACT 실행 신호로 만들지 않는다.

| 과적합 방지   | 적용 원칙                                                                                                                                                |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 생성 규칙     | 전투·능력 ID, 콘텐츠 이름, R11S의 고정 시각이나 전멸기 목록을 하드코딩하지 않는다. 아래 ID는 검증 대상의 식별자일 뿐이다.                                |
| 공통 알고리즘 | 원본 시각·발생 순서·관측 multiplicity·trace 종료·반복되는 근거로 판단한다. 수집 길이의 우선순위도 일반적인 전투 기간으로 정한다.                         |
| 회귀 자료     | 다른 raid와 dungeon의 기존 입력도 재생성하고, 합성 테스트의 ID·시각·복수 개체 수를 변화시킨다. R11S에서 이벤트가 늘어난 것만으로 개선을 승인하지 않는다. |
| 불확실성      | 다른 시각의 파동·근거 부족·상관 분기를 임의로 합치지 않는다. 특정 전투를 맞추기 위한 예외 대신 미해결 근거를 남긴다.                                     |

## 확인한 문제와 구현 순서

| 순서 | 문제                                                                              | 개선                                                                                                                                                              | 검증 기준                                                                                                      |
| ---- | --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 1    | 같은 시각의 같은 이름·능력에 복수 인스턴스가 있으면 대응이 모호한 반복으로 제외됨 | 정확히 같은 원본 밀리초의 시전들을 표시용 파동으로 분석한다. 개수·원본 인덱스는 보존하고 다른 시각의 반복은 합치지 않는다.                                        | Comet·Mammoth Meteor·후반 다중 타격을 복원한다. 50ms 차이의 별개 발생과 실제 반복 회차는 임의로 합치지 않는다. |
| 2    | 마지막 고유 기준점 이후에는 오른쪽 기준점이 없어 표시하지 못함                    | 왼쪽 기준점에 연결한 접두부 정렬로 관측 종료까지 확장한다. 조기 처치·중단을 오른쪽 검열로 취급하고 내부 누락과 구분한다.                                          | 첫 Heartbreak Kick과 연속 타격이 완료 로그의 처치 시점 차이 때문에 사라지지 않는다.                            |
| 3    | 전멸기를 관측한 긴 로그는 kill=false라 학습에서 제외됨                            | 공통 기준점 이후의 부분 진행 학습에 미처치 로그도 사용한다. 최소 둘 이상의 독립 trace에서 강제 대응된 발생만 새 표시 일정에 채택하고 반대·미확정 관측을 보존한다. | 실제 B462 관측을 원본과 연결한다. 짧은 로그의 관측 종료를 미래 시전의 부재 증거로 쓰지 않는다.                 |
| 4    | 후반 대안 ID와 VFX·보조 신호가 섞임                                               | 관측된 선택 이력·국소 분기와 표시 역할을 구분한다. cactbot의 무시 ID 목록은 검토 근거로 쓰며 일괄 삭제 규칙으로 사용하지 않는다.                                  | 관측되지 않은 경로 조합이나 가짜 종료 신호 없이 누락·표시 잡음을 줄인다.                                       |

수집 파일은 기존 검증기를 통과해야 한다. 원본은 `logs/`, 수집 계획·생성 KDL·근거는 `out/`에 저장한다. 문서에는 입력 trace와 SHA-256, 완료 여부·기간·후반 능력 관측 범위를 별도로 기록해 재현성을 유지한다.

## 검증과 완료 판단

| 검사           | 의미                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 합성 회귀      | 같은 시각의 복수 개체, 근접 시각의 별도 파동, 반복 누락, 조기 처치, 내부 누락을 구분한다. rstest·proptest·insta를 활용한다. |
| 실제 로그 비교 | 시전 파동별 포함·제외와 종료 시점 이후 미관측을 분리한다. 이벤트 정의 수 증가만으로 성공을 판정하지 않는다.                 |
| KDL 단독 재생  | evidence 없이 제어·시각 동작을 검사한다. FFLogs cast를 Ability로 투영한 시험은 합성 입력 가정임을 표시한다.                 |
| 미검사         | 실제 ACT 신호 동등성, 외부 실행기, 모든 미관측 기믹·분기 경로는 별도 확인 전까지 보장하지 않는다.                           |

각 구현 단위를 리뷰·회귀 검사한 뒤 커밋하고, 아래에 확보 자료와 실제 복원 범위를 갱신한다.

## 구현 결과

| 단위               | 결과                                                                                                                                     | 제한                                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 정확한 밀리초 파동 | 기존 완료 로그 3개에서 112 → 157개 정의. B414·B427·B453·B459의 표시를 복원. 원본 관측과 `alignment.waves`의 batch·instances 연결을 보존. | 정의 증가에는 옵션 본문도 포함한다. 전체 커버리지 비율이 아니며 B454·마지막 기준점 뒤·대안 ID는 아직 미해결. |

공통 알고리즘에는 위 표의 전투 ID·능력 ID·시각을 사용하지 않는다. `mine`의 원본 그래프 가중치와 관측은 복수 개체 수를 유지하고, 공통 기준점과 생성 정렬은 정확한 밀리초의 표시 파동을 사용한다.
